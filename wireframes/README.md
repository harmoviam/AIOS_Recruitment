## 📋 Project Overview

AIOS (AI Operating System) is a modern, AI-first SaaS platform designed specifically for Indian recruitment agencies and staffing firms. This wireframe suite represents a billion-dollar quality AI recruitment operating system built for India-first staffing agencies.

### Key Features
- ✨ AI-powered candidate matching and recommendations
- 💬 WhatsApp-integrated shared inbox (central to workflows)
- 🎯 Modern Kanban board for candidate pipeline management
- 📅 Smart interview scheduling with calendar integration
- 📊 Executive analytics and performance dashboards
- 🚀 Mobile-first responsive design
- 🤖 Conversational AI assistant interface

## 🎨 Design System Highlights

### Color Palette
- **Primary**: Indigo (#6366f1) + Pink (#ec4899) Gradient
- **Success**: Green (#10b981)
- **Warning**: Amber (#f59e0b)
- **Danger**: Red (#ef4444)
- **Neutrals**: Slate grayscale

### Typography
- **System fonts** for performance
- **3-tier hierarchy**: Headlines (700), Body (400), Labels (500)
- **Responsive scale**: From 0.75rem to 2.5rem

### Spacing
- **8px base grid** system
- Consistent padding and margins
- Flexible gap system for flexbox

### Components
- Buttons (primary, secondary, danger, ghost)
- Input fields with validation
- Cards with hover effects
- Modals and dialogs
- Badges and tags
- Kanban cards

## 📱 Responsive Design

### Breakpoints
```
Mobile:          < 576px
Tablet Small:    576px - 768px
Tablet:          768px - 1024px
Desktop:         1024px - 1440px
Desktop Large:   > 1440px
```

### Mobile Optimizations
- Bottom tab navigation (4-5 icons)
- Full-width cards
- Simplified modals
- Touch-friendly targets (min 44x44px)
- Swipe gestures support
